# 🏡 Airbnb – MEN Stack

A simple Airbnb-style backend built with MongoDB, Express.js, and Node.js. Includes user authentication, property listings, and booking features.

---

## 🧰 Tech Stack

- **MongoDB** – NoSQL database
- **Express.js** – Web framework
- **Node.js** – Backend runtime
- **Mongoose** – MongoDB ODM
- **JWT** – Authentication
